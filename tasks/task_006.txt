# Task ID: 6
# Title: Create tRPC Mutation for Generating and Storing R&W Content
# Status: pending
# Dependencies: 4, 5
# Priority: high
# Description: Implement a new tRPC mutation (e.g., `adminReadingWriting.generateAndStoreContentSets`) that can be called (e.g., by an admin or an automated process) to initiate the generation of R&W content sets for a specific difficulty level and quantity. This mutation will call the Gemini API client function (TS1.1.3) and the content storage service (TS1.2.2).
# Details:
Add a new tRPC mutation, potentially in `src/server/api/routers/admin.ts` or a new `readingWritingAdmin.ts`. This mutation should accept parameters for `difficultyLevel` and `numberOfSets`. Inside the mutation, call the Gemini API client function (Task 4) to generate content. If successful, pass the generated content to the storage service function (Task 5) to save it to the database. Implement appropriate error handling and ensure the endpoint is protected (e.g., requires admin authentication).

# Test Strategy:
Write integration tests for the tRPC mutation. Test calling the mutation with valid and invalid inputs. Verify that it correctly triggers the Gemini API client and the storage service (potentially using mocks for external dependencies). Check for correct error responses on failure and successful database insertion on success.
