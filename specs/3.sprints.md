## Sprint 3: Vocabulary Module - Practice

*   **Goal:** Implement the vocabulary practice feature using spaced repetition and AI grading.
*   **Epics:** Practice Schema & API, SRS Logic, Practice UI, AI Grading.

**Tasks:**

1.  **Schema & API:**
    *   [X] Update `prisma/schema.prisma`: Add `PracticeSession` (with `VOCABULARY` type), `WordPracticeLog` models. Add SRS fields to `Word` model.
    *   [X] Run migration: `pnpm prisma migrate dev --name add-vocab-practice`. *(Combined migration done)*
    *   [X] Implement `practice.startVocabSession` mutation (input: array of wordBankIds; creates `PracticeSession` record).
    *   [X] Implement `practice.getNextVocabWord` query (input: practiceSessionId; uses SRS logic to select the next word, returns word details).
    *   [X] Implement `practice.submitVocabAnswer` mutation (input: practiceSessionId, wordId, userSentence, easeChosen; calls AI grading, saves `WordPracticeLog`, updates `Word` SRS fields).
    *   [X] Implement `practice.getVocabSessionSummary` query (input: practiceSessionId).
    *   [X] Add procedures to `src/server/api/routers/vocab.ts`.
    *   [X] Define Zod schemas in `src/schemas/practice.schema.ts`.

2.  **Spaced Repetition System (SRS):**
    *   [X] Implement SRS algorithm logic in `src/lib/srs/sm2.ts` (or similar). Functions needed: `calculateNextReview(word: Word, easeChosen: number): { interval, easeFactor, repetitions, nextReviewDate }`.
    *   [X] Integrate SRS logic into `practice.getNextVocabWord` (select words where `nextReviewDate <= now()` ordered by date) and `practice.submitVocabAnswer` (update word SRS fields based on `calculateNextReview`).

3.  **UI - Practice Session:**
    *   [ ] Create page `src/app/vocabulary/practice/page.tsx`.
    *   [ ] Add UI to select Word Banks to practice (Shadcn `Checkbox` or multi-select).
    *   [ ] Add "Start Practice" button calling `practice.startVocabSession`. Redirect to a dynamic route like `src/app/vocabulary/practice/[sessionId]/page.tsx`.
    *   [ ] Create `src/app/vocabulary/practice/[sessionId]/page.tsx`:

        *   Display the word (`Word.text`).
        *   Provide `Textarea` for user to enter a sentence.
        *   Provide buttons for ease feedback (Again, Hard, Good, Easy).
        *   On submit, call `practice.submitVocabAnswer`. Show loading state.
