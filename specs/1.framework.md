# Framework Development Plan - SAT Study App

This document details the setup and configuration for the core framework components: tRPC, Prisma, Authentication, Environment Variables, and API structure.

## 1. Project Structure (Recap & Refinement)

```
src/
├── app/                  # Next.js App Router (Pages & Layouts)
├── components/           # Shared React Components (UI & Feature)
│   ├── ui/               # Shadcn UI Components
│   └── features/         # Feature-specific components (e.g., vocab, reading)
├── lib/                  # Core logic, utilities, external API clients
│   ├── api/              # Gemini API client wrapper
│   ├── auth/             # Authentication configuration (NextAuth.js)
│   ├── db/               # Prisma client instance and setup
│   ├── srs/              # Spaced Repetition System logic
│   ├── trpc/             # tRPC client setup
│   └── utils.ts          # General utility functions (e.g., cn for Tailwind)
├── schemas/              # Zod schemas for validation (tRPC inputs, forms)
├── server/               # Backend-specific code (tRPC routers, context)
│   ├── api/              # tRPC Routers
│   │   ├── root.ts       # Root tRPC router merging sub-routers
│   │   ├── routers/      # Sub-routers per feature (e.g., vocab.ts, reading.ts, user.ts)
│   │   └── trpc.ts       # tRPC procedure builders, middleware (e.g., auth)
│   └── db/               # Prisma schema (schema.prisma)
├── styles/               # Global CSS
├── types/                # TypeScript type definitions
└── env.mjs               # Environment variable validation (using T3 Env)
```

## 2. Database Setup (Prisma & PostgreSQL)

*   **Database Choice:** PostgreSQL (Recommended for scalability and features). Alternatives like SQLite can be used for simpler local development.
*   **ORM:** Prisma.
*   **Initial `schema.prisma`:**

```prisma
// This is your Prisma schema file,
// learn more about it in the docs: https://pris.ly/d/prisma-schema

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql" // Or "sqlite" for local dev
  url      = env("DATABASE_URL")
}

model User {
  id            String    @id @default(cuid())
  name          String?
  email         String?   @unique
  emailVerified DateTime?
  image         String?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  accounts      Account[]
  sessions      Session[]
  wordBanks     WordBank[]
  practiceSessions PracticeSession[]
  answerAttempts AnswerAttempt[] // Added relation
}

// Models for NextAuth.js
model Account {
  id                String  @id @default(cuid())
  userId            String
  type              String
  provider          String
  providerAccountId String
  refresh_token     String? @db.Text
  access_token      String? @db.Text
  expires_at        Int?
  token_type        String?
  scope             String?
  id_token          String? @db.Text
  session_state     String?

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([provider, providerAccountId])
}

model Session {
  id           String   @id @default(cuid())
  sessionToken String   @unique
  userId       String
  expires      DateTime
  user         User     @relation(fields: [userId], references: [id], onDelete: Cascade)
}

model VerificationToken {
  identifier String
  token      String   @unique
  expires    DateTime

  @@unique([identifier, token])
}

// --- Application Specific Models ---

model WordBank {
  id          String   @id @default(cuid())
  name        String
  description String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  userId      String
  user        User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  words       Word[]
}

model Word {
  id                String    @id @default(cuid())
  text              String    // The word itself
  definition        String?   // AI Generated
  sampleSentence    String?   // AI Generated
  translation       String?   // AI Generated (e.g., Chinese)
  createdAt         DateTime  @default(now())
  updatedAt         DateTime  @updatedAt
  wordBankId        String
  wordBank          WordBank  @relation(fields: [wordBankId], references: [id], onDelete: Cascade)

  // SRS Fields
  interval          Int       @default(1) // Days until next review
  easeFactor        Float     @default(2.5)
  repetitions       Int       @default(0) // Number of times reviewed
  nextReviewDate    DateTime  @default(now())

  practiceLogs      WordPracticeLog[]

  @@unique([wordBankId, text]) // Ensure unique words within a bank
}

model WordPracticeLog {
  id                String    @id @default(cuid())
  wordId            String
  word              Word      @relation(fields: [wordId], references: [id], onDelete: Cascade)
  practiceSessionId String
  practiceSession   PracticeSession @relation(fields: [practiceSessionId], references: [id], onDelete: Cascade)
  timestamp         DateTime  @default(now())
  userSentence      String    // Sentence user provided
  isCorrect         Boolean   // Based on AI grading
  aiFeedback        String?   // Explanation from AI
  easeChosen        Int       // User feedback on difficulty (e.g., 1=Again, 2=Hard, 3=Good, 4=Easy) - used by SRS
}

enum PracticeType {
  VOCABULARY
  READING_WRITING
}

model PracticeSession {
  id            String    @id @default(cuid())
  userId        String
  user          User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  type          PracticeType
  startTime     DateTime  @default(now())
  endTime       DateTime?
  score         Float?    // Overall score (e.g., percentage for R&W)
  difficulty    Int?      // For R&W (1-5)
  createdAt     DateTime  @default(now())

  // Relations
  vocabLogs     WordPracticeLog[] // If type is VOCABULARY
  passage       Passage?          // If type is READING_WRITING
  answerAttempts AnswerAttempt[]  // If type is READING_WRITING
}

model Passage {
  id                String    @id @default(cuid())
  content           String    @db.Text // The reading passage text
  difficulty        Int       // Difficulty level it was generated for
  createdAt         DateTime  @default(now())
  practiceSessionId String    @unique // One passage per R&W session
  practiceSession   PracticeSession @relation(fields: [practiceSessionId], references: [id], onDelete: Cascade)
  questions         Question[]
}

enum QuestionType {
  MULTIPLE_CHOICE // Add others if needed
}

model Question {
  id          String       @id @default(cuid())
  passageId   String
  passage     Passage      @relation(fields: [passageId], references: [id], onDelete: Cascade)
  questionText String
  type        QuestionType @default(MULTIPLE_CHOICE)
  options     String[]     // Array of multiple-choice options
  correctAnswer String     // The correct option text
  explanation String?      // Explanation for the correct answer (AI generated)
  createdAt   DateTime     @default(now())

  answerAttempts AnswerAttempt[]
}

model AnswerAttempt {
  id                String    @id @default(cuid())
  practiceSessionId String
  practiceSession   PracticeSession @relation(fields: [practiceSessionId], references: [id], onDelete: Cascade)
  questionId        String
  question          Question  @relation(fields: [questionId], references: [id], onDelete:Cascade)
  userId            String
  user              User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  selectedAnswer    String
  isCorrect         Boolean
  timestamp         DateTime  @default(now())
}

```

*   **Setup:**
    *   Install Prisma: `pnpm add -D prisma` and `pnpm add @prisma/client`
    *   Initialize Prisma: `pnpm prisma init --datasource-provider postgresql`
    *   Run initial migration: `pnpm prisma migrate dev --name init`

## 3. API Layer (tRPC)

*   **Purpose:** Provides type-safe API communication between frontend and backend.
*   **Setup:**
    *   Install dependencies: `pnpm add @trpc/server @trpc/client @trpc/react-query @trpc/next @tanstack/react-query zod`
    *   Configure tRPC server (`src/server/api/trpc.ts`, `src/server/api/root.ts`).
    *   Configure tRPC client (`src/lib/trpc/client.ts`).
    *   Set up API route handler (`src/app/api/trpc/[trpc]/route.ts`).
    *   Wrap root layout with QueryClientProvider (`src/app/layout.tsx`).
*   **Core Concepts:**
    *   **Context:** Provides access to DB, session, etc., for procedures.
    *   **Procedures:** Define API endpoints (queries, mutations). Use Zod for input validation.
    *   **Routers:** Group related procedures (e.g., `vocabRouter`, `userRouter`).
    *   **Middleware:** Implement reusable logic, like authentication checks.

*   **Initial Routers (`src/server/api/routers/`):**
    *   `user.ts`: Procedures related to user data (e.g., get profile).
    *   `vocab.ts`: Procedures for WordBank CRUD, adding words, fetching practice words, submitting practice results.
    *   `readingWriting.ts`: Procedures for starting sessions, generating questions, fetching sessions, submitting answers, fetching history.

*   **Authentication Middleware (`src/server/api/trpc.ts`):**
    *   Create a `protectedProcedure` that verifies user authentication using the session context before allowing access.

## 4. Authentication (NextAuth.js)

*   **Purpose:** Handle user login, registration, and session management.
*   **Setup:**
    *   Install: `pnpm add next-auth @auth/prisma-adapter`
    *   Configure API route (`src/app/api/auth/[...nextauth]/route.ts`).
    *   Configure Prisma Adapter.
    *   Choose providers (e.g., Google, Email). Obtain necessary credentials.
    *   Update `schema.prisma` with NextAuth models (already included above).
    *   Wrap root layout with `SessionProvider`.
    *   Add Sign In/Sign Out buttons/logic to UI (e.g., in Navbar).
*   **Integration:**
    *   Access session data on the server via tRPC context.
    *   Access session data on the client using `useSession` hook.

## 5. Environment Variables

*   **Management:** Use `.env` file for local development. Use platform's environment variable system for deployment (e.g., Vercel).
*   **Validation:** Use `T3 Env` (`@t3-oss/env-nextjs`) for runtime and build-time validation of environment variables. (`src/env.mjs`)
*   **Required Variables:**
    *   `DATABASE_URL`: Connection string for Prisma.
    *   `NEXTAUTH_URL`: Application URL for NextAuth.
    *   `NEXTAUTH_SECRET`: Secret key for NextAuth token encryption.
    *   `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`: (If using Google provider).
    *   `EMAIL_SERVER_USER`, `EMAIL_SERVER_PASSWORD`, `EMAIL_SERVER_HOST`, `EMAIL_SERVER_PORT`, `EMAIL_FROM`: (If using Email provider).
    *   `GEMINI_API_KEY`: API key for Google Gemini.

## 6. Core Libraries & Utilities (`src/lib`)

*   **`utils.ts`:** General helpers, including `cn` function from Shadcn UI for merging Tailwind classes.
*   **`db/`:** Prisma client instance export.
*   **`auth/`:** NextAuth configuration options export.
*   **`trpc/`:** tRPC client setup and provider export.
*   **`api/`:** Wrapper/client for interacting with the Gemini API. Handle API key, request formatting, basic error handling.
*   **`srs/`:** Implementation of the Spaced Repetition System algorithm. Functions to calculate next review dates, update intervals/ease factors based on user feedback.
