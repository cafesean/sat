I want to create a nextjs SAT study app that is mobile friendly and attractive for young students. This app will have several modules:

- Vocab Practice: I can upload words to a word bank. a list of words can be pasted into a text box and it will be auto parsed. Every word added will use the Gemini API to auto generate definitions, sample sentence, chinese translations and save to the database. A practice module will use spaced repetition technique where the user will be presented words 1 by 1, and  tested on the word by entering a sentence using the word, and AI will grade the sentence and determine if the answer proves understanding or not. Use algorithms normally used in spaced repetition to determine how often a word shows up again. Word banks can be practiced against separately or together.

- Reading and Writing: a practice module for reading and writing will allow the user to "Start Practice Session" and AI will automatically generated a set of SAT-style/ level questions containing passages, question type, questions, and multiple choice answers which will all be stored in the database. The student will then choose an answer from the multiple choice options. Upon submitting answers, the user can immediately get an explanation of the answer along with the correct answer and correct/incorrect. A real-time score tally will be constantly displayed. The practice session will be accessible later from a practice history list. There can be a setting for the difficulty from 1 to 5 set prior to each session that will have the AI generate questions based on the difficulty level selected.
